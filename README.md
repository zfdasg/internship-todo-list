# Todo 待办清单

企业实习课程基础项目，使用 HTML、CSS 和原生 JavaScript。

## 运行

直接用浏览器打开 `index.html`，无需安装依赖。

## 功能

- 添加、删除任务
- 标记完成和取消完成
- 查看任务数量、清除已完成任务
- 使用 localStorage 保存数据，刷新后保留
- 适配手机屏幕

## 文件说明

- `index.html`：页面结构
- `style.css`：页面样式
- `script.js`：任务操作和本地存储

## 使用说明

输入任务并点击添加，勾选复选框表示完成。数据仅保存在当前浏览器，清理浏览器数据会删除任务。
